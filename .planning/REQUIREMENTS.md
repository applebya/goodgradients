# Requirements: Good Gradients v2

**Defined:** 2026-02-22
**Core Value:** A massive, well-curated gradient library with instant code export — beautiful to browse, fast to use, and genuinely fun to interact with.

## v1 Requirements

### Theming

- [ ] **THEME-01**: User can toggle between light and dark mode via a UI control

### Gradient Collection

- [ ] **GRAD-01**: Gallery contains 1000+ algorithmically generated gradients from color theory
- [ ] **GRAD-02**: Gradients are categorized by mood (Warm, Cool, Vibrant, Muted, Pastel, Dark, Neon, Earth)
- [ ] **GRAD-03**: Each gradient has an evocative name inspired by nature, materials, or trends

### Motion & Delight

- [ ] **MOTN-01**: Gallery cards animate in with staggered fade/slide entrance effects
- [ ] **MOTN-02**: Smooth transitions between gallery and detail views
- [ ] **MOTN-03**: Hovering an animation option temporarily applies that animation to ALL visible gradient cards

### Design Audit

- [ ] **DSGN-01**: Improved spacing and layout with visual rhythm and breathing room
- [ ] **DSGN-02**: Distinctive brand identity — premium/clean aesthetic, not generic template look

## v2 Requirements

### Theming

- **THEME-02**: Auto-detect OS theme preference on first visit
- **THEME-03**: Persist theme choice in localStorage across sessions

### Gradient Collection

- **GRAD-04**: Gradients tagged by use case (Hero background, Card, Button, Text overlay)

### Motion & Delight

- **MOTN-04**: Spring physics for hover effects, button presses, modal opens

### Design Audit

- **DSGN-03**: Typography refresh — better font choices and visual hierarchy
- **DSGN-04**: Gradient card component redesign — more polished and distinctive

## Out of Scope

| Feature                          | Reason                                                   |
| -------------------------------- | -------------------------------------------------------- |
| Backend/API                      | Staying static on GitHub Pages — free, simple            |
| User-submitted gradients         | Future feature, needs backend                            |
| Scraping external gradient sites | Generating our own — own the content, avoid legal issues |
| Community features               | No accounts, comments, or sharing beyond URL             |
