<task type="auto">
  <name>Task 1: Create theme infrastructure (CSS variables + hook + utility)</name>
  <files>src/index.css, src/lib/theme.ts, src/hooks/useTheme.ts</files>
  <action>
**src/lib/theme.ts** -- Create a theme utility module:
- Export `THEME_STORAGE_KEY = "goodgradients-theme"` constant
- Export `type Theme = "dark" | "light"`
- Export `getStoredTheme(): Theme` -- reads from localStorage, returns "dark" if not set or on error
- Export `setStoredTheme(theme: Theme): void` -- writes to localStorage with try/catch
- Export `applyTheme(theme: Theme): void` -- adds/removes `.light` class on `document.documentElement`. Dark has NO class (default), light adds `.light`.

**src/hooks/useTheme.ts** -- Create the React hook:

- Import from `@/lib/theme`
- `useTheme()` returns `{ theme: Theme, toggleTheme: () => void }`
- Initialize with `getStoredTheme()` on mount
- `toggleTheme` flips theme, calls `setStoredTheme` and `applyTheme`
- Use `useEffect` to call `applyTheme` on mount with initial theme
- Use `useCallback` for `toggleTheme`

**src/index.css** -- Refactor CSS variables for dual-theme support:

- Keep existing `:root` block as the dark theme defaults (current values are already dark)
- Add `.light` class block with light theme variables:
  - `--background: 0 0% 98%` (near-white)
  - `--foreground: 0 0% 9%` (near-black)
  - `--card: 0 0% 100%` (white)
  - `--card-foreground: 0 0% 9%`
  - `--muted: 0 0% 93%`
  - `--muted-foreground: 0 0% 45%`
  - `--border: 0 0% 88%`
  - `--ring: 0 0% 65%`
- Add `transition: background-color 200ms ease, color 200ms ease` to `body` for crossfade
- Add `transition: background-color 200ms ease, border-color 200ms ease, box-shadow 200ms ease` to `*` selector for card/element transitions
- Ensure scrollbar styles also adapt: light scrollbar track/thumb for `.light`
  </action>

- `src/index.css` contains both `:root` (dark) and `.light` variable blocks
  </verify>

**src/components/ThemeToggle.tsx** -- Create the floating toggle:
- Import `useTheme` from `@/hooks/useTheme`
- Render a `<button>` with `fixed bottom-4 right-4 z-50` positioning (bottom-right corner, above scroll-to-top)
- Size: `w-10 h-10 rounded-full` with subtle backdrop blur and semi-transparent background
- Dark mode appearance: `bg-white/10 hover:bg-white/20 text-white/70 hover:text-white`
- Light mode appearance: Use `.light` parent selector -- `bg-black/5 hover:bg-black/10 text-neutral-600 hover:text-neutral-900`
- Icon: Sun icon (circle + rays) for dark mode (clicking switches to light), Moon icon for light mode (clicking switches to dark). Use simple inline SVG paths, no external icon library needed.
- Add `aria-label="Switch to {opposite} mode"` for accessibility
- Add `transition-all duration-200` for hover smoothness
- Respect `prefers-reduced-motion` -- skip crossfade transition if reduced motion preferred

**src/App.tsx** -- Wire the theme:

- Import `ThemeToggle` from `./components/ThemeToggle`
- Import `useTheme` from `@/hooks/useTheme`
- Call `useTheme()` at app root level to initialize theme on mount (ensures `.light` class applied before first paint)
- Place `<ThemeToggle />` inside the root `<div>`, after `<GitHubCorner />`
- Update root div: change `className="min-h-screen bg-neutral-950 text-white"` to `className="min-h-screen bg-background text-foreground"` so it uses CSS variables instead of hardcoded dark colors
- Review other hardcoded `bg-neutral-950` or `text-white` references in App.tsx and convert to variable-based equivalents where they reference the page background/foreground

**index.html** -- Prevent flash of wrong theme:

- Add a small inline `<script>` in `<head>` before any CSS loads:
  ```js
  (function () {
    try {
      if (localStorage.getItem("goodgradients-theme") === "light")
        document.documentElement.classList.add("light");
    } catch (e) {}
  })();
  ```
  This ensures the `.light` class is applied before first paint if user previously chose light mode.
