  <name>Task 1: Redesign GradientCard for landscape layout and minimal info</name>
  <files>src/components/GradientCard.tsx</files>
  <action>
Redesign the GradientCard component to match user decisions:

**Aspect ratio change:**

- Replace `aspect-video` (16:9 is already close) with explicit `aspect-[16/9]` to be precise about landscape ratio
- This is already close to the current `aspect-video` but makes the intent explicit

**Remove hex color codes from cards:**

- Remove the entire "Color Swatches" section at the bottom of the card (the `flex gap-2` block that shows color dots + hex values)
- Color details belong in the detail view, not on browsing cards per user decision

**Simplify card content area:**

- Keep: gradient name (h3)
- Keep: mood category badge (but simplify -- just the category name, no tag icon prefix)
- Keep: quick action buttons (copy, favorite) overlaid on the gradient swatch
- Remove: tags section (the Badge elements with Tag icons) -- too much info for a minimal card
- Remove: description paragraph (`line-clamp-2`) -- keep cards minimal per user decision
- The content area below the swatch should just be: name on left, category badge on right, single row

**Card content area height reduction:**

- With description and color swatches removed, the content area shrinks to ~40-48px (single row: name + category)
- Use `px-4 py-3` for content area padding (was `p-4`)

**Theme-aware colors:**

- Replace `bg-neutral-900/50` with `bg-card/50`
- Replace `border-neutral-800` with `border-border`
- Replace `hover:border-neutral-700` with `hover:border-border/80` or similar that works in both themes
- Replace `text-white` on name with `text-card-foreground`
- Replace `text-neutral-400` on description (removed) with theme variable if needed elsewhere
- For overlay buttons on the gradient swatch, keep the `bg-black/40` overlays (they need to be visible on any gradient)

**Light mode card treatment (per user decision):**

- In light mode, cards should have subtle drop shadows. Add: `shadow-none dark:shadow-none` as default, then `.light &` or a conditional class that adds `shadow-sm` for light mode. Alternatively, add `shadow-sm` and cancel it in dark with a dark variant. Simplest: use Tailwind's dark variant -- but since we use a class-based theme (`.light`), configure this with a Tailwind variant. Actually, simpler: just add `shadow-sm` and in dark mode override with `shadow-none`. OR: Use the CSS approach: in `index.css` add `.light .gradient-card { box-shadow: 0 1px 3px rgb(0 0 0 / 0.1); }`.

**SkeletonCard update:**

- Update SkeletonCard to match the new minimal layout (remove hex swatch skeletons, remove description skeleton)
