  <name>Task 1: Typography system and brand color refinement</name>
  <files>src/index.css, index.html</files>
  <action>
**Typography -- font choice (Claude's discretion per CONTEXT.md):**
- Add Inter as the primary UI font. It is the standard for Linear/Vercel-style clean interfaces.
- In `index.html`: add a `<link rel="preconnect" href="https://fonts.googleapis.com">` and `<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>` in the `<head>`.
- Add `<link href="https://fonts.googleapis.com/css2?family=Inter:wght@400;500;600;700&display=swap" rel="stylesheet">` to load Inter.
- In `src/index.css`: set `body { font-family: 'Inter', system-ui, -apple-system, sans-serif; }` in the `@layer base` block.

**Typography hierarchy:**

- In `src/index.css`, add utility classes or `@layer base` rules:
  - Headings (h1-h3): `font-weight: 600` (semibold), `letter-spacing: -0.025em` (tight tracking -- a Linear signature)
  - Body text: `font-weight: 400`, normal tracking
  - Small labels/badges: `font-weight: 500`, `font-size: 0.75rem`, `letter-spacing: 0.025em` (slightly wider for legibility at small sizes)
  - Mono text (color codes in detail view): keep existing `font-mono`

**Brand accent color (Claude's discretion per CONTEXT.md):**

- Add a subtle accent color variable for interactive highlights. Choose a desaturated violet/indigo that works in both themes:
  - Dark: `--accent: 250 30% 60%` (soft violet, not vibrant)
  - Light: `--accent: 250 40% 50%` (slightly richer for contrast on white)
  - `--accent-foreground: 0 0% 100%` (white text on accent)
- Register in `@theme` block: `--color-accent: hsl(var(--accent))` and `--color-accent-foreground: hsl(var(--accent-foreground))`
- This accent is for focus rings, active filter states, and subtle UI highlights -- NOT for gradient-related colors

**Refined base styles:**

- Update `body` in `@layer base`: add `text-rendering: optimizeLegibility` for sharper text
- Increase base font size slightly if needed: `font-size: 15px` or keep at default 16px (Claude's judgment)
- Ensure link/interactive elements use the accent color for focus rings: `:focus-visible { outline: 2px solid hsl(var(--accent)); outline-offset: 2px; }`

**GradientCard.tsx -- Premium card polish:**
- Card name: apply `font-semibold tracking-tight` (consistent with heading hierarchy)
- Category badge: `text-xs font-medium tracking-wide uppercase text-muted-foreground` for a refined label feel

- Ensure card `border-radius` is `rounded-xl` (12px) -- rounder corners feel more premium than `rounded-lg` (8px)

- Logo/brand name: `text-lg font-semibold tracking-tight` (not too large, confident)

- If there are any borders or dividers in the header, make them `border-border/50` (subtler)
- Filter controls should feel lightweight: smaller text, muted colors, accent on active state
